proyecto: Pedido de Cafeteria

1. Clona o descarga el repositorio desde GitHub en tu equipo.

2\. Abre `frmPedidoCafeteria.csproj` en \*\*Visual Studio\*\*.

3\.  Compila la solución.

Lo que realiza el proyecto:

Puedes elegir entre una lista definida de productos para crear tu carrito virtual teniendo opciones de entregas o extras cada uno con costos adicionales, por ultimo tiene el total de la compra.

nota: se debe seleccionar del listado un producto y poner agregar para tener en su carrito virtual.

Eventos implementados:

1.-Load

2.-SelectedIndexChanged

3.-Validating

4.-TextChanged

5.-CheckedChanged

6.-Click

Reglas de negocio:

1.-Selección desde el catálogo y precio real

2.-Subtotal por ítem en lvPedido

3.-Cálculo del Total General 

4.-Validación de datos obligatorios y cantidad

5.-Principio DRY en el cálculo
